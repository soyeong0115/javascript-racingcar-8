# javascript-racingcar-precourse
초간단 자동차 경주 게임을 구현한다.

---
## 📝 구현 기능 목록

### 입력
- [ ] 경주할 자동차 입력받기
  - `경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)` 출력
  - 잘못된 입력값일 경우 throw문을 통해 예외 발생
    
    - [예외] 입력값이 없을 경우
    - [예외] 자동차 이름이 5자를 넘는 경우
    - [예외] 자동차 이름이 중복되는 경우


- [ ] 시도할 횟수 입력받기
  - `시도할 횟수는 몇 회인가요?` 출력
  - 잘못된 입력값일 경우 throw문을 통해 예외 발생
    
    - [예외] 입력값이 없을 경우
    - [예외] 입력값이 자연수가 아닐 경우 ex) 문자, 음수, 소수, 0


### 자동차 경주 진행
- [ ] 자동차 경주 게임 진행
  - 자동차 수만큼 무작위 값 선정하기
  - 무작위 값이 4이상인 자동차는 전진
  - 무작위 값이 4미만인 자동차는 정지
  - 시도할 횟수가 0이 되면 게임 종료


### 출력
- [ ] 차수별 실행 결과 출력하기
    - 전진 or 정지할 때마다 출력
      
- [ ] 최종 우승자 출력하기
    - 단독 우승자 `최종 우승자 : pobi` 출력
    - 공동 우승자 `최종 우승자 : pobi, jun` 출력
